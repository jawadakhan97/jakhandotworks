Crab Cannery Simulator

Featured Project

historicalsocialist realismcharacter driven

Set foot in the Crab Cannery Ship

Reimagining of the literary classic, Kani Kōsen『蟹工船』by Takiji Kobayashi as a character driven narrative game. Make decisions as one of three playable characters in the sandbox that is the Crab Cannery Ship. Play the same scenario as different characters, each requiring different skills and approaches.

Key Features

  • Unique abilities, skills for each character
  • Non-linear approach
